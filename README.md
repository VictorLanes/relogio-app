# Relógio

App de relógio para Android: **alarmes, relógio mundial, cronômetro, temporizadores** e **widgets** para a tela inicial.

## Widgets
- **Digital**: 14 fontes (LCD 7 segmentos, futurista, condensada, cursiva, neon retrô, terminal…)
- **Digital empilhado**: hora sobre os minutos
- **Flip**: cartões estilo relógio de mesa
- **Analógico**: 6 mostradores (clássico romano, minimalista, neon, esportivo, transparente, dourado), com ou sem ponteiro de segundos
- **Data**: dia da semana e data completa
- **Completo**: hora, data e próximo alarme

Todos são redimensionáveis, com cor do texto, cor e transparência do fundo, 12/24 h, segundos e fuso horário de outra cidade.
Para mudar um widget já colocado: segure o widget → Configurações (ou abra o app → Widgets).
